About

What this is

A curated listing of upcoming London politics and ideas events, including in-person, hybrid, and online, across the spectrum — libertarian, conservative, progressive, foreign policy, and abundance/YIMBY. This initial edition uses fictional events to demonstrate the calendar. Every sample is labelled Simulated.

Window
The list and calendar show the next 3 weeks, in UK time (BST / GMT). A multi-day event is listed on each day it runs inside that window.
Sources
The preview uses fictional hosts, speakers and listings. Real listings will link to their original event pages when added.
Times
UK time (BST / GMT).
Maintenance
Real events will be added after source verification. Sample dates roll forward to keep the preview populated; real event dates will stay fixed.
Install
Add this page to your home screen to open it like an app. On iPhone or iPad: Share, then Add to Home Screen. On Android or desktop Chrome: Install app, or the browser’s install menu. Refresh loads the latest published events.
Newsletter
Sign up for the free Sunday roundup through our London Google Form. It asks for your name, email and institution, with optional interests and event preferences. Signup is opt-in. The roundup will use verified events when real listings are available.
